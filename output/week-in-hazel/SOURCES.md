Files and inline review comments were fetched for selected feature/quality stories. Bot boilerplate was filtered from the editorial reading, not mistaken for human discussion. All 690 current remote branch records were captured through paginated GitHub API calls. The commit sample traverses their unique tip SHAs and deduplicates shared history by SHA, using `--since-as-filter` and exact UTC committer timestamp bounds. It includes distinct rebased/cherry-picked objects, even when patch content is equivalent. It does not count local-only branches, deleted remote branches, unique patches, pushes, lines of code, or hours worked. There were 65 tips with committer dates inside the week; we do not label that as a push count or completeness measure. Events data is capped at 300 and is not used for the headline statistics.

Co-author matching checks case-insensitive Co-authored-by trailers mentioning Claude/Anthropic or OpenAI/Codex/ChatGPT. This is a declared attribution signal. Signature matching checks a gpgsig header and does not verify the signature or attribute it to an assistant. The categories overlap; they are not a partition. Absence is unknown assistance. Tuesday's rise includes merges and should not be read as a rise in original work.
